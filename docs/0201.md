## 0102. Describir que debería ocurrir para la clase Libro al prestar un ejemplar
En caso de que se intente prestar un libro, este debería comprobar antes de todo si tiene ejemplares disponibles. Si tiene disponibilidad se realizaría el préstamo (relacionando las clases libro con socio) y debería cambiarse la cantidad de libros disponibles con el mismo nombre. Si el libro no está disponible, el préstamo no se realiza y no cambia la candidad de libros disponibles.

## 0103. Discribir el siguiente flujo:
* Se da de alta un libro con 3 ejemplares.
* Se dan de alta dos socios.
* El primer socio toma prestado el libro (¿tiene éxito?).
* El segundo socio intenta tomar el mismo libro (¿tiene éxito?).
* El primer socio devuelve el libro.
* El segundo socio vuelve a intentar tomar el libro (¿tiene éxito?).
